Cách nhập cấu hình trên iPhone / iPad
  1. Mở trang này bằng Safari, bấm “Tải cấu hình ProxyPin” và xác nhận tải file.
  2. Mở ProxyPin → Script (Kịch bản) → Import (Nhập), chọn phtrunghieu-proxypin.json trong Tệp → Tải về. Vị trí Tải về có thể nằm trong iCloud Drive hoặc Trên iPhone.
  3. Bật Script và mục PHTRUNGHIEU vừa nhập. Nếu đã có script PHTRUNGHIEU cũ, tắt hoặc xóa bản cũ để tránh chạy trùng.
  4. Nếu chưa thiết lập HTTPS: bật giải mã HTTPS trong ProxyPin, cài CA của app rồi bật tin cậy trong Cài đặt → Cài đặt chung → Giới thiệu → Cài đặt tin cậy chứng nhận.
  5. Bật bắt gói/VPN của ProxyPin rồi đóng và mở lại game để tải cấu hình.

ProxyPin iOS 1.3.3 chưa hỗ trợ mở app và tự nhập script bằng URL Scheme. File này chỉ chứa script cấu hình, không chứa key game hay Menu Secret.

LIVE TikTok lỗi khi bật ProxyPin?
  1. Tải file blacklist TikTok ở trên. Đây là file bộ lọc domain, không nhập vào Script.
  2. Trong ProxyPin: Settings → Proxy Filter → Proxy Domain Blacklist → Import, chọn phtrunghieu-tiktok-blacklist.json và bật Enable.
  3. Nếu Proxy Domain Whitelist đang bật, Blacklist không có hiệu lực. Giữ whitelist nếu nó đã chỉ chứa đúng host game; nếu muốn dùng blacklist này thì tắt whitelist trước.
  4. Blacklist chỉ bỏ giải mã HTTPS, kết nối vẫn có thể đi qua ProxyPin. Muốn thử bỏ qua proxy hệ thống: thêm tên miền gốc và wildcard vào Settings → Proxy ignores domain, phân cách bằng dấu chấm phẩy (;).
  5. Bấm Done trên bàn phím để lưu ô Proxy ignores domain, dừng/bật lại VPN ProxyPin, rồi đóng/mở lại TikTok trước khi thử LIVE.

Danh sách khởi đầu: tiktokv.com, tiktokcdn.com, ibyteimg.com, tiktok.com, byteoversea.com và các tên miền con. Không phải danh sách đầy đủ mọi host LIVE. Không dùng Request Blocking để chặn TikTok và không thêm host cấu hình game vào danh sách bỏ qua.
