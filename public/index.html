03 / QUICK ANSWERS

Trước khi mở menu.

Key game và Secret Key có giống nhau không?

Không. Key game dùng để xác thực trong game. Secret Key được cấp sau bước xác thực để đăng nhập menu web của key đó.

Muốn chuyển sang thiết bị khác?

Trong bot đã mua key, dùng /resetkey để reset liên kết thiết bị. Mỗi key được reset miễn phí một lần trong mỗi 7 ngày kể từ lần reset thành công; thời hạn key không thay đổi.

ProxyPin ảnh hưởng TikTok trên iOS?

Menu web có file blacklist tên miền TikTok riêng, nhập trong Proxy Domain Blacklist thay vì Script. Đây là loại trừ giải mã HTTPS, không phải cam kết toàn bộ lưu lượng TikTok sẽ bỏ qua VPN.
